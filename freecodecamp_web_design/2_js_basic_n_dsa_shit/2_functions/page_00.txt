1) What Is the Purpose of Functions, and How Do They Work?
ans:
    Functions are reusable blocks of code that perform a task or
    calculate a value.

    - declaring a function:
        function greet() {
            console.log("hello");
        }
    
    - calling/ invoking a function:
        greet();

    Parameters vs arguments:
        parameters are a placeholder in function definition
        arguments are actual value when calling fucntion

        function greet(name) {  //name is parameter
            console.log("Hello, " + name + "!");
        }

        greet("Alice"); // "Alice" is the argument

    Return values:
        - every function returns a value
        - if u dont use return, it retuns Undefined

            function add(a, b) {
                return a + b;
            }

            let result = add(3, 4); // 7
    
    Anonymous Functions
        - Functions without a name can be stored in variables

        const sum = function (num1, num2) {
            return num1 + num2;
        };

        console.log(sum(3, 4));

    Default values
    - used wen u give no argument to method invoke..

            function greet(name = "Guest") {
                console.log("Hello, " + name + "!");
            }

            greet(); // Hello, Guest!


2) What Are Arrow Functions, and How Do They Work?
    ans:
    Arrow functions are another shorter way to write funtions.
    
    regular:
        function greetings(name) {
            console.log("Hello, " + name + "!");
        }
    
    arrow:
        const greetings = (name) => {
            console.log("Hello, " + name + "!");
        };

    Differences:
        - no function keyword
        - use => (arrow)
        - stored in a variable usally

    i) If there is 1 parameter... no need for parentheses
        const greetings = name => {
            console.log("Hello, " + name + "!");
        };

    ii) multiple parameters means - need parenthese
        const add = (a, b) => {
            console.log(a + b);
        };

        add(5, 3); // 8

    iii)  for one line fucntions remove 

{} as well
            const greetings = name => {
                console.log("Hello, " + name + "!");
            };
        will be:
            const greetings = name => console.log("Hello, " + name + "!");

    iv) arrow functions can return values
        normal method:
            const calculateArea = (width, height) => {
                return width * height;
                };

            console.log(calculateArea(5, 3)); // 15

        shorter version: (implicit return)

            const calculateArea = (width, height) => width * height;

            console.log(calculateArea(5, 3)); // 15

        Note: dont write return if ur using short form without parentheses

3) What Is Scope in Programming, and How Does Global, Local, and Block  
    Scope Work?
    ans:

    Scope = where a variable can be accessed in your code.

    i) global scope
    variable can be accessed anywhere

        let name = "John"
        function greet() {
            console.log(name);
        }

    ii) local/function scope
    variable declared inside a function can only be used inside that    
    function

        function greet() {
            let message = "Hello";
            console.log(message);
        }

        console.log(message) // this ... doesnt work

    iii) block scope
    let and const created inside {} only exist within that block.
    Blocks include if, for, while, etc.
