The optional chaining operator (?.) in JavaScript 
allows you to safely access nested object properties or 
call methods without throwing a TypeError if an 
intermediate property is null or undefined.

Instead of raising an error when trying to access a 
property on an uninitialized or missing object 
(such as person.address.street), using ?. 

(e.g., user?.profile?.address?.street) short-circuits the evaluation and safely returns undefined. 

This prevents runtime crashes and keeps code concise 
and robust when dealing with incomplete or uncertain 
data structures.

------

Object destructuring is an ES6 JavaScript feature that 
allows you to unpack properties from an object into 
separate variables in a single, concise statement.

--
const person = { name: "Alice", age: 30, city: "New York" };

const { name, age } = person;

console.log(name); // Alice
console.log(age); 
--

One powerful ascept is that u can assign extracted value
to variabels with different names

--
let person = { name: "Alice", age: 30, city: "New York" };

let { name: personName, age: personAge } = person;

console.log(personName); // Alice
console.log(personAge); //  30
--

default values if any problem..

let person = { name: "Alice", age: 30, city: "New York" };
let { name, age, country = "Unknown" } = person;

console.log(country); // Unknown

**nested objects**

const recipe = {
  name: "Chocolate Cake",
  ingredients: {
    flour: "2 cups",
    sugar: "1 cup"
  }
};

const { ingredients: { flour } } = recipe;

console.log(flour); // "2 cups"
